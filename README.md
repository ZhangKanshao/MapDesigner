# MapDesigner

Windows 离线地图软件。支持 Europa Universalis V 与 Crusader Kings III 底图、缩放平移、按游戏区分的行政区划和名称查询，以及国家编辑、领土着色、首都、国名、Snapshot 和整图 PNG 导出。

## 运行

安装 Node.js 和 pnpm 后，在项目目录执行：

```powershell
pnpm install
pnpm start
```

Electron 42 的 Windows 运行文件需在首次安装后执行 `node node_modules/electron/install.js` 下载。准备好依赖后，可双击根目录的 `启动MapDesigner.cmd` 打开桌面窗口。

也可以直接用浏览器打开 `index.html`，查看同样的页面流程，或执行 `pnpm preview` 后打开 http://127.0.0.1:4173。

Electron 界面使用本地 HTML/CSS/JavaScript；当前三屏原型无需前端构建。地图引用 `assets/maps/eu5/basemap.png`，模板缩略图引用同目录 `basemap-preview.png`。生成脚本会同步这些资源。原始地图和生成脚本见 `assets/maps/eu5/` 与 `scripts/render_basemap.py`。

右下角滑块以 5% 为一步，支持 100%–2000% 缩放。100% 表示完整地图适应窗口；放大后按住鼠标左键拖动地图，也可通过滚动条查看各处，将滑块调至 100% 可适应窗口，不再提供复位按钮。拖动到地图边缘会停止，鼠标松开后结束拖动。

工具栏将“粒度”“设置”“操作”放在同一行；“粒度”后并排“区划”和“着色”。两者均支持地块、省份、区域、地区、次大陆、大洲。区划选择“地块”为原底图；其他等级在原底图上加入该级的黑线，保留地块灰色细线。切换时保留缩放和视口。仅标记不同陆地行政单元之间的分界，不描海岸线，不显示海区分组边界。“着色”独立控制单次着色或擦除的范围。

重新生成底图后，执行 `python scripts/render_admin_maps.py` 同步生成行政区划底图。边界来自本机 `definitions.txt` 的五级嵌套，原始线宽为 2 像素（Location 细线为 1 像素），分界两侧各占 1 像素；河流保持浅蓝色。生成报告见 `assets/maps/eu5/admin-boundaries.json`。游戏有少量颜色标识未列入层级定义，保留原样，不补造行政归属。

“隐藏边界”会隐藏 Location 和上级行政边界，再次点击恢复当前粒度的边界。名称按钮仅显示图标“A”，开启后，地图指针变为 A；移动鼠标显示指向位置在当前粒度下的名称。缩放、拖动和隐藏边界不会改变名称查询粒度。再次点击可关闭名称模式。

名称与命中数据通过 `python scripts/prepare_map_tools.py` 生成，包括无边界底图和原始像素对应的逐行区段索引，索引按需加载，可在浏览器、本地文件和 Electron 中离线使用。中文来源为本机游戏中的 `region_names`、`province_names`、`area` 和默认 `location_names`，已复制到 `assets/maps/eu5/localization/`；缺少中文时显示游戏标识，未定义上级归属时明确提示。

“创建国家”打开悬浮表单，名称和介绍可留空，颜色通过色块展开调色盘选择，支持预设、色相、饱和度/明度和 RGB 整数输入（0–255）。名称去掉首尾空格后检查重复，忽略大小写及全半角差异；空名称允许重复。颜色按实际 RGB 精确去重。确认后在地图左上角显示“色块 + 国家名称”，未命名国家用序号区分。国家列表按 EU5 地图保存在当前浏览器/桌面环境的本地存储中；取消不保存。

创建入口位于透明国家列表右上角的“＋”，不显示国家计数。国家颜色还禁止使用海洋/河流色 `#b9dfee`、荒地色 `#dedede`、地块边界色 `#969696` 和行政区划黑线色 `#000000`。

点击国家名称打开编辑界面，可修改名称、介绍和颜色，或删除国家。修改颜色同步更新已有领土；删除国家将还原其全部领土。编辑时允许保持自身名称和颜色，仍检查与其他国家及底图保留颜色的冲突。

单击国家右侧的画刷选择它，再单击地图，按“着色粒度”批量分配领土；再次单击同一画刷取消选择。拖动超过 4 像素仍只平移，不触发着色。名称模式、国家着色和擦除工具互相切换。“擦除”按相同粒度还原白色地块或灰色荒地。河流、海洋、湖泊以及可见边界由像素遮罩保护。

“荒地着色”默认关闭。打开后允许分配荒地，关闭时清除所有荒地归属并恢复灰色，普通陆地归属保留。领土和开关状态自动保存到当前环境本地存储，刷新后恢复。

着色模式使用画笔光标，擦除模式使用橡皮光标，按住拖动时仍显示抓手。擦除工具使用纯橡皮图标；荒地着色为圆球左右滑动的开关。

工具栏分为“设置”和“操作”：隐藏边界、荒地着色集中在设置组，均为圆球滑动开关；显示名称、擦除、撤销集中在操作组。后续二选一的设置统一复用 `.setting-switch` 和 `.setting-switch-label` 样式，保持开启时圆球在右侧、关闭时在左侧。

逆时针箭头图标为“撤销”，也支持 Ctrl+Z。可撤销着色、擦除，以及国家的创建、修改、删除；设置开关不计入撤销。关闭荒地着色时同步清理历史记录中的荒地归属差异，撤销不会重新打开开关或恢复已清除的荒地着色，普通陆地的撤销历史保留。批量着色算一步，无实际改变的点击不占一步。记录地块归属差异和必要的国家信息，不保存整张地图快照；最多保留 30 步、150,000 条地块变更，达到上限时移除最旧记录（至少保留最近一步）。刷新后不保留撤销历史。表单输入框内 Ctrl+Z 保留文本编辑行为。

着色辅助资源通过 `python scripts/prepare_paint_tools.py` 在底图和名称索引生成后重建，包括各显示粒度的保护遮罩和地块类型数据。运行时只创建视口大小的着色画布，复用原始行区段索引定位，不修改游戏原文件。

操作组最右侧的存档图标打开保存窗口。Snapshot 与 PNG 分别保留名称和文件夹；名称默认包含北京时间的年月日时分秒，可修改。可选择文件夹，也可输入完整路径。默认分别保存到 `saves/snapshots/` 和 `saves/png/`；目录不存在时会创建，同名文件需再次点击“覆盖保存”才替换。

Snapshot 扩展名为 `.mapdesign`，使用带版本的 JSON，包含国家、领土、荒地开关、两种粒度、边界显示、名称模式、当前工具及缩放/视口中心。底图版本指纹用于防止地块归属错配。首页“加载地图”从默认快照文件夹选择文件，加载后可继续编辑；加载前完整校验，失败保留当前地图，成功后清空撤销历史。

PNG 保存原始分辨率 16384 × 8192 的整张地图，包含当前着色、边界显示与粒度、国名、首都和地图配色；不受当前窗口大小、缩放和查看位置影响，不包含国家列表、缩放控件、工具栏和指针提示。桌面版和浏览器使用相同的整图绘制流程，保存会等待当前编辑与排版完成。

完整路径选择和 PNG 导出建议通过桌面版或 `pnpm preview` 使用。直接打开 `index.html` 时可加载快照；浏览器允许文件夹选择时可保存快照，但本地文件来源限制可能阻止 PNG 导出。

每次打开保存窗口，Snapshot 默认使用项目目录下的 `saves/snapshots`，PNG 默认使用 `saves/png`；两者独立保存，临时修改路径不会改变下次打开时的默认目录。

国家列表采用半透明白色背景；标题和创建加号固定在顶部，仅列表内容滚动，滚动条位于左侧，国家文字和操作图标保持从左到右排列。

按住国家的色块或名称拖动，可自由调整列表顺序；插入位置显示提示线，拖到列表上下边缘自动滚动。排序保持当前选中国家和领土归属，支持撤销，并随本地记录和 Snapshot 保存。

首页提供“创建地图”“加载地图”“导入地图”“设置”四个入口。创建地图选择 EU5 后初始化空白项目，清空国家、着色和撤销记录，并恢复默认视图。加载地图列出 `saves/snapshots` 中的 `.mapdesign` / `.json`，按修改时间排序；点击条目加载并继续编辑。导入地图校验选中的快照后，将其原始内容复制到默认快照文件夹，不自动打开、不更改当前编辑状态；重名时自动添加编号，保留已有文件。

桌面版和本地预览服务直接访问默认快照文件夹。直接通过浏览器打开 `index.html` 时，浏览器会要求用户授权选择该文件夹（请选 `saves/snapshots`），随后在当前会话中使用该授权读取和复制文件。

移除左侧导航栏，地图和首页使用全部窗口宽度。顶部路径采用 14px 字号，可点击“首页”返回首页，点击“创建地图”返回底图选择页；当前页面通过 `aria-current` 标记。

全局设置分为操作设置、文件设置、外观设置。框外下方等宽居中的“保存设置”和“恢复默认设置”仅处理当前分类；恢复默认值会立即应用并保存。快捷键右侧的铅笔打开录入窗口，按下按键或组合键完成修改，重复与保留组合即时检查；删除图标清空绑定，可以有多个未设置项。快捷键仅在地图页面生效，表单和弹窗不会触发地图操作。默认：撤销 Ctrl+Z、保存 Ctrl+S、擦除 E、显示名称 A、切换边界 B、创建国家 C、放大 5% 为 =、缩小 5% 为 -；方向键 ↑↓←→ 分别滚动地图，每次 120 像素，支持长按。操作设置还可选择滚轮功能，默认缩放地图（每步 50%，保持鼠标指向的位置），可改为滚动窗口。

文件设置可分别修改 Snapshot 和 PNG 默认目录，支持完整路径输入或文件夹选择；保存设置时创建目录，不移动已有地图。加载和导入跟随 Snapshot 目录。外观支持跟随系统、浅色、深色，以及系统默认、微软雅黑、等线、宋体、楷体、黑体、仿宋、Arial、Times New Roman、Consolas 字体，程序主题不会改变底图和导出地图颜色。

桌面版和本地预览服务将全局设置保存到项目 `saves/settings.json`，两者共用；直接打开 `index.html` 时使用当前浏览器的本地存储。浏览器直接打开文件时，仍需授权目录访问。全局设置独立于 Snapshot。

外观更改立即预览；未保存就离开外观分类或整个设置页面时，恢复已保存的主题和字体。字体预览框位于下方独立一行，文字居中。旧版本设置升级时保留自定义绑定和已清空的快捷键；新增方向键若与旧绑定冲突，对应的新绑定留空。

全局设置中的快捷键、滚轮功能、主题和字体均占满一行，选项控件靠右。滚轮缩放步长为 50%（最初速度的十倍），缩放滑块与缩放按钮仍保持 5% 步长。地图工具栏的显示开关分组改名为“外观”。

地图标题栏最右侧的齿轮打开“当前地图设置”，可修改水域、荒地、细粒度边界、粗粒度边界颜色，支持色块选择或输入 #RRGGBB。保存设置应用于当前地图；恢复默认值会立即应用并保存。颜色不能与现有国家颜色相同，创建或编辑国家时也会按当前地图配色检查冲突。配色通过 Snapshot 的可选 `mapAppearance` 字段保存，旧快照使用默认配色，新建地图恢复默认配色；PNG 导出保留当前配色、边界和着色。

地图调色通过修改索引 PNG 的 PLTE 调色板及校验值实现，地块和河流像素分类、边界粒度和着色保护遮罩保持不变。使用 `python scripts/prepare_palette_sources.py` 在底图资源更新后生成 `assets/maps/eu5/palette/` 中的离线调色数据，须在所有底图及边界图生成完成后运行。

全局设置和当前地图设置中的“恢复默认设置”均立即应用并保存，无需再点击保存；全局设置仍仅恢复当前分类。当前地图标题栏采用对称八齿齿轮图标。字体选项增加楷体、黑体、仿宋、Arial、Times New Roman、Consolas，并沿用即时预览和未保存退出回退的行为。

地图“外观”组的“隐藏国名”开关（默认关闭，即显示国名），与原有鼠标查看地名的 A 工具独立。具名且有领土的国家会自动显示一个名称，无名、无领土或缩放后文字过小的国家暂不显示。

名称按国土形状调整字号。新版允许少量越界及跨海：按文本框和每行实际文字范围估算，本国陆地覆盖率至少 60%、总陆地覆盖率至少 65%、其他国家覆盖率最多 10%。海洋和荒地可作为少量延伸空间，评分仍优先本国陆地。包括未命名国家在内的其他国家都会参与越界检查；用户已选择的名称样式和不透明度不会被默认值更新覆盖。

根据国土面积与距离区分主体和小块飞地。小于最大块约 30% 的国土一般不参与联合布局，因此不列颠加阿尔斯特的名称以不列颠为中心。面积相近、距离较近的主要国土会尝试分组，要求文字范围实际覆盖每个主要部分，不能只是放大空白文本框；不列颠加法兰西可跨英吉利海峡排版。距离过远或联合排版无法满足陆地覆盖率时，回退到主体国土。

倾角由国土主轴和覆盖率共同选择，允许到 ±90°，避免文字倒置；明显狭长的国家优先沿主轴单行排列。已用 EU5 真实区域验证智利和越南的大幅倾斜，以及英法跨海联合排版。中文换行保留最长行字符数与行数至少 1.5 的规则：四字仅单行，五字允许 3+2。拼音文字按单词边界候选换行，实际文本框长宽比至少 1.5。

着色、擦除、荒地开关、国家改名或删除、撤销会重新排版；拖动和缩放只更新显示位置与尺寸。小于约 6 屏幕像素的名称暂不显示，可放大查看。当前地图设置可独立选择国名字体、颜色、不透明度（0–100%，默认 75%）。文字有自动黑白对比描边，填色和描边作为一层使用统一不透明度。开关及样式保存在 Snapshot 的可选 `countryLabels` 字段，也保留在当前编辑的本地记录；未记录国名设置的旧快照和新建地图默认显示国名，字体为楷体。PNG 导出等待排版完成并包含当前名称。恢复当前地图默认设置会恢复这些选项。

`python scripts/prepare_country_labels.py` 在名称索引与 `project-meta.js` 更新后重建 `assets/maps/eu5/lookup/country-label-geometry.js`。v2 数据保存每个格子的 Location 像素权重、陆地和荒地比例，并带底图指纹。首次启用且存在具名领土时才加载；预览和桌面版优先使用 worker，直接打开本地文件时使用可分段让出执行的离线回退。

长条形国家改用较小字号和疏排字距，不再依靠放大字形填满国土。中文按字、拼音文字优先按词分布；单词可使用适度字距。沿国土长轴选取南北或东西分布点，并在每个位置附近寻找本国陆地落点，因此名称可以顺着弯曲国土分布，“越南”两字可分别位于北部和南部。单字名称也会缩小字号。字号目标不超过原排版候选的 65%，并进一步受国土短轴宽度限制；无法安全疏排时使用较紧凑的回退。

疏排模式分别检查每个字/词及其实际墨迹范围，字符之间的空隙不计入越界或陆地比例；仍保留本国陆地为主和少量外国覆盖的限制。相邻字形保持间隔，避免重新挤在局部宽阔处。英法跨海分组的决策采用缩字前的尺寸比较，不因疏排缩小字号而退回只在法兰西显示。疏排是根据国土自动计算的结果，随地图编辑更新，并通过原有 snapshot 和 PNG 流程恢复和导出。

国家列表右侧依次为画刷和星形首都按钮。画刷选择该国进行着色，再次点击取消；名称点击编辑，拖动名称排序。左键进入选点模式，自动显示鼠标悬停的 Location 名称（不受行政区划粒度影响），在地图点击本国已经着色的陆地 Location 指定或更换首都；选点不修改着色粒度或领土，仍可拖动、缩放，Esc 或再次点击星标取消。右键星标清除首都。地图会独立显示带白色描边的金色星星，不受国家名称开关影响，PNG 导出保留星标。国家列表的金色星标表示当前有效首都，悬停显示 Location 名称；首都不再归属本国时，标记暂时隐藏、列表提示失效，指定记录保留，撤销领土变化可恢复。

首都保存为国家对象的可选 `capital: {locationId,x,y}`，随本地记录和 Snapshot 保存。旧 Snapshot 无此字段时视为未指定；加载会检查 Location、陆地类型及点坐标是否位于相应地块，允许恢复已暂时失效的首都记录。国家改名、改色、排序保留首都；指定、清除首都支持原有撤销。新建地图清空国家及首都。

有效首都优先于领土面积：国名使用包含首都 Location 的连通领土，不再被更大的海外殖民地拉走。此时不跨海合并其他孤立领土；未指定或首都已失效时，继续使用原有面积与跨海分组规则。首都所在块即使未进入最大的 24 个区域，也会独立保留。若首都块小到无法容纳可读名称，暂不显示国名，而不是迁到殖民地。

编辑国家中可选择或删除首都：选择会保存表单并进入地图选点；删除在确认表单时生效，取消保留原首都。国家列表加宽且右侧留白，创建加号置于最右侧；工具栏不再显示截断的操作提示。长条国家仅在中文字或完整单词之间拉开距离，单个拼音单词保持连贯；较方正国家字号在有效覆盖约束下缩小至原排版的 78%。

国名排版优先水平：普通连续领土比较水平与 ±45° 内的倾角，效果接近时优先水平，倾斜的综合排版分数提高约 2% 时即可采用倾斜，只有明显细长（主轴比至少 3.5）的国家才启用大角度及分字排版。跨海共同标题保留跨岛屿的倾角选择。旋转轴按 180° 周期换向，统一保持在 [-90°, 90°)，避免临界角截断产生不合理的方向。


地图平滑显示：底图地形、国家着色和行政区划现统一由 `src/vector-map.js` 绘制，`paint-layer` 保存完整地图视口。相邻 Location 共享同一条矢量弧线；源像素轮廓以 0.65 像素容差简化，并在转折附近最多 0.45 像素内圆滑连接。可见边界使用抗锯齿和圆角，粗边界为细边界的 2 倍，海岸线不描边；隐藏边界会同时隐藏两种线条。细线在缩小时保留最低显示宽度。只绘制与视口相交的地块和弧线，路径缓存复用。

`python scripts/prepare_vector_map.py` 从现有 Location 行索引、地形分类和河流资源重建 `lookup/vector-map.js`、用于保留旧资源的 `vector-rivers.png` 及对应调色脚本（运行时已不使用该河流位图）。矢量数据为 gzip 压缩的脚本资源，支持离线文件和桌面环境。河流已由独立的平滑矢量轮廓最后覆盖，保留河宽变化、支流汇流和河中小岛，不参与国家着色。原始 PNG 保留为加载底图资源。点击、粒度着色、首都、撤销及 Snapshot 的 Location ID 与格式均不变，PNG 导出使用同一矢量画面。

`node scripts/check-vector-map-ui.cjs` 验证矢量图层、边界抗锯齿、隐藏边界、所有行政区划粒度和领土数据不变，并将放大效果图保存到 `output/vector-borders-*.png`。


矢量河流：执行 `python scripts/prepare_vector_rivers.py` 从原始河流图提取河道完整轮廓，以 0.3 原像素容差简化，再在显示时作轻微圆滑和抗锯齿。按 512 像素分块并保留 2 像素重叠，避免平移时处理跨越大片大陆的整条河网；使用有向轮廓和非零填充保留洞及分支，重叠区域不会出现接缝。输出为离线脚本 `lookup/vector-rivers.js`，运行时随地图加载，并按水域颜色绘制，无需河流 PNG 遮罩。选择、着色、擦除、首都仍使用原始 Location 数据，旧 snapshot 无需转换。

`node scripts/check-vector-rivers-ui.cjs` 以原始河流像素独立采样的 512 个河内/河岸点检查轮廓覆盖，验证本地文件、浏览器和桌面环境的河流保护、PNG 导出及 snapshot 恢复。


低倍率渲染：地块填色和区划边界按约 6000 个源轮廓点的预算分批提交 Canvas，单个地块的外环和洞保持同一批。河流资源记录每个源分块包含的全部外环和洞，按完整分块绘制；避免将整个视口河网合成一个超大 Path2D，触发 Chromium 在世界概览时静默丢失填色。`node scripts/check-vector-zoom-ui.cjs` 验证浏览器和桌面在 100%、150%、200%、220%、225%、230%、500%、2000% 及回缩后的陆地、荒地和边界可见性。

普通国家的国名不再按长宽比强制水平：评估 0°、±15°、±30°、±45° 和限制在该范围内的国土主轴方向。比较字号、本国/外国/水域覆盖与位置，给接近方形的国家更强的水平偏好；只有倾斜明显改善排版时才采用。明显狭长国家及跨海标题保留原有的大角度规则。

中等倾斜的水平偏好进一步降低：非近方形国土在 45° 时的角度扣分由 12% 降为 4%，倾斜胜出阈值由 12% 降为 2%；近方形国土仍有额外水平偏好，避免重新出现普通方正国家大幅旋转。


国名避让：排版以实际领土面积从小到大进行，给小国先留位置，面积相同按国家 ID 稳定排序，国家列表拖动排序不会改变避让结果。使用带描边余量的旋转矩形作分离轴碰撞检测，疏排国名逐字/逐词检查；候选位置与字号在原有领土覆盖约束下避让已放好的国名，无法放下时暂不显示。较大连续领土额外缩小字号（平滑增加至约 28%，叠加原有默认缩字），并重新检查缩小后的位置，避免跨海国名缩进水域。领土、名称、字体变动会重新排版，snapshot 保留原有设置与数据格式。

`node scripts/check-label-collisions-ui.cjs` 验证实际法国、瑞士与德国相邻国名的文字/描边像素无交叠，大国文字框面积受控，列表排序不影响排版，snapshot 与 PNG 保持一致。

国名海面偏好：普通连续领土按文字实际墨迹和整体文字框的陆地覆盖率加重海面扣分，减少为了放大字号而越过海岸的排版。默认缩字后重新比较候选中心的陆地、本国覆盖和中心距离，优先将国名放进内陆；多块相近领土的跨海标题采用较温和的海面扣分，保留跨海峡的共同国名。近方形国家仍优先水平。

国名越界扣分进一步增强：综合整体文字框与实际墨迹的本国覆盖率，以平方权重压低落到领土外的方案，并加重外国覆盖扣分。疏排逐字/逐词至少要求文字框 85%、墨迹框 88% 位于本国，再在候选位置中择优；达不到时沿用缩字重试，避免末尾单字明显伸出国境。海面偏好、相邻国名避让及跨海共同标题规则继续生效。

字号重新拟合：原有的小字号只用来寻找较好的内陆中心；选点后在多个可行中心重新搜索安全字号，再仅留一次轻度余量。重新放大仍检查国名碰撞、本国覆盖及海面覆盖，不因放大而放宽到明显越界。中等国家允许更灵活的文字框占地，大国（所选连续领土达到约 15 万源像素面积）保留约 22% 的文字框面积上限，避免大国国名再次过大。`node scripts/check-label-refit-ui.cjs` 比较类似截图的保加利亚领土在旧缩字与重新拟合下的字号及覆盖率。

疏排字距：对整组字/词联合选点，以候选序列搜索替代逐字贪心选择。按相邻字形之间的可见空隙限制差异（最大与最小之比不超过约 1.25），并在满足本国覆盖、避让、顺序和最小间隔的序列中优先更均匀者；无可行序列时缩字重试。弯曲国土使用二维距离比较，不再只让主轴投影近似等距。字母语言仍以完整单词为单位。

整图 PNG 导出采用带余量的离屏分块绘制、逐行压缩写入 PNG，避免创建整张 536 MB 的 RGBA 画布；导出窗口显示进度。国名和首都复用页面的绘制逻辑，边界/国名开关及配色继续生效，导出不移动视口也不修改 snapshot 或编辑状态。`node scripts/check-full-map-export-ui.cjs` 验证全图尺寸、窗口外着色及首都、国名/边界开关、不同缩放下图像像素一致，以及浏览器和桌面实际保存流程。

保存/加载窗口：保存窗口底部仅保留居中的保存按钮，右上角 × 仍可关闭。加载窗口先单击高亮选择 snapshot，再使用居中并排的“加载”“删除”按钮；未选中或忙碌时按钮禁用，不再点击列表直接加载。删除仅作用于默认快照文件夹内所选的普通 .mapdesign/.json 文件，拒绝目录、符号链接和越界路径，删除后自动更新列表且不改变当前编辑状态。浏览器本地目录句柄使用对应文件删除 API。
## Crusader Kings III 模板

首页 → 创建地图 → Crusader Kings III → 选择 867、1066 或 1178 年法理，即可创建空白地图。行政区划与着色粒度使用男爵领、伯爵领、公国、王国、帝国，不加入霸权。模板由本机游戏文件生成，采用平滑矢量地块、边界和河流；支持国家着色、首都、国名、Snapshot 与 9216 × 4608 整图 PNG 导出。

三个日期分别为 867.1.1、1066.9.15、1178.10.1。法理归属以安装版本的 `common/landed_titles` 为基础，再应用 `history/titles` 中截至对应日期的 `de_jure_liege` 变更，不使用实际领主 `liege`，也不模拟开局后的法理漂移。底图保持空白，不导入剧本的实际国家领土。

EU5 与各 CK3 日期的本地编辑记录分别保存。Snapshot 记录模板、法理日期及源文件指纹，加载时自动切换到对应模板；导入仅复制到默认 Snapshot 文件夹。已有 EU5 Snapshot 继续可用。

重建 CK3 资源：用安装了 NumPy、Pillow 的 Python 执行 `python scripts/prepare_ck3_template.py`。默认只读取 `D:\Steam\steamapps\common\Crusader Kings III\game`，输出到 `assets/maps/ck3`，不修改游戏文件。`manifest.json` 记录源文件哈希，`history-audit.json` 记录各日期应用的法理变更。更新游戏并重建资源会改变指纹，旧版本 Snapshot 不会被误用到新底图。

`node scripts/check-ck3-template-ui.cjs` 验证桌面与浏览器的模板选择、日期法理差异、伯爵领着色、地名、首都、国名、Snapshot 保存/加载/导入、EU5 数据隔离及整图 PNG 尺寸。

边界显示下拉框提供“显示地块边界”“显示政治边界”“隐藏边界”。地块模式保留细粒度与所选行政粒度分界；国家模式以细粒度边界相同的线宽描绘不同国家之间，以及国家与未着色普通陆地之间的交界；不描海岸、同一国家内部或未着色荒地的交界，荒地着色后参与国家边界判断。快捷键 B 按上述顺序循环。当前地图设置新增国家边界颜色，默认为黑色；粗粒度边界默认深灰色 `#555555`。Snapshot 保存显示模式与颜色，旧 Snapshot 自动补齐国家边界默认颜色并按原开关恢复；整图 PNG 使用相同模式。`node scripts/check-border-display-ui.cjs` 验证 EU5、CK3 的交界绘制、旧存档兼容、快捷键与国家边界颜色导出。


加载地图列表的每个 Snapshot 右侧提供铅笔按钮。点击后输入不含扩展名的新名称，按 Enter 或 ✓ 确认，Esc 或 × 取消。保留原扩展名和文件内容，拒绝无效名称及同名覆盖；重命名后选中新的文件，可继续加载或删除。桌面版、本地预览和浏览器目录句柄均支持。
